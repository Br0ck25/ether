# Ether

Ether is an open-source server that presents itself to Plex apps as a Plex Media
Server, but holds no media. Its library is a filtered TMDB catalogue; when
someone presses play, Ether finds a release on Usenet and streams it in about
five seconds.

See [docs/design.md](docs/design.md) for the design.

## Legal

Ether ships no content, no Usenet providers and no indexers. Owners supply
every account and are responsible for what they access.
